# Local Setup

1. Install Node.js LTS: https://nodejs.org/en/download
2. Install Git: https://git-scm.com/downloads
3. Clone the repository.
4. Open the repository in VS Code (or run `code .` from inside it).
5. Run `npm install`.
6. Run `npm run dev`.
7. Open http://localhost:3000
8. Before pushing changes, run `npm run build` to confirm the production build succeeds.
