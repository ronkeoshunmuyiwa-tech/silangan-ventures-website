# Architecture

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Content:** stored in `src/content/`, separated from page/layout files
- **Components:** reusable pieces in `src/components/` (`layout/`, `sections/`, `ui/`)
- **Images:** production images in `public/`; editable sources in `assets/source-images/`
- **Hosting (planned):** Vercel
- **Included:** static company + product-validation pages only
- **Not included:** database, authentication, payments, customer dashboard, AI engine — see Final Scope Rule in the Step 5 plan
